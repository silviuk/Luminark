Captured from the current application on 25 October 2026. Includes Dashboard,
Schedule & Automation, Settings, and the tray mini window in both themes.

The main window stays at its default size (1040 x 780 logical window dimensions;
1026 x 773 captured visible bounds). The tray window keeps its natural 360 x 369

because the desktop capture helper excludes tray-only windows from enumeration.

applications or desktop content appear in these images.

`screenshots.json` records their ordered captions and SHA256 digests. Publishing
validates the version, PNG dimensions, safe filenames and checksums, replaces only
the en-us desktop screenshots, and preserves other listing art.
