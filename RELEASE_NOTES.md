What's New in Luminark v1.1.19:

• Global Brightness Hotkeys for External Keyboards:
  - Added customizable global shortcuts to Increase Master Brightness (default Ctrl+Alt+Up) and Decrease Master Brightness (default Ctrl+Alt+Down) across all linked monitors.
  - Perfect for Logitech MX Keys (via Logi Options+ shortcut mapping or direct keys), macro pads, and external mechanical keyboards.
  - Configurable adjustment step size (1%, 2%, 5%, 10%) in Settings.
  - Smooth key holding: holding down the brightness shortcut smoothly steps brightness without requiring individual key releases.

• Laptop Hardware Fn Brightness Key Synchronization:
  - Built-in real-time WMI event watcher listening to native laptop brightness changes.
  - Pressing your laptop's physical Fn brightness keys automatically mirrors the new brightness level across all connected external (DDC/CI) monitors in real time!

• Windows 11 On-Screen Display (OSD) Overlay:
  - Added a non-activating, lightweight, Fluent-styled brightness flyout that displays when adjusting brightness via hotkeys or tray scroll without interrupting active games or applications.
