What's New in Luminark v1.1.11:

• Screen Off & Keep-Awake on Lock:
  - Added "Lock & Screen Off" action and global hotkey (Win+J).
  - Automatically powers down internal laptop and external displays natively without putting the PC to sleep.
  - Windows 11 Modern Standby (S0) laptops stay 100% awake with network and background tasks running.
  - Touching any key or mouse instantly wakes the screen at full normal brightness to unlock.

• External Monitor Video Input Switching:
  - Switch monitor inputs (DisplayPort, HDMI, USB-C) directly from the flyout or Main Window via DDC/CI.
  - Assign custom friendly names (e.g. Work PC, Gaming Rig) and filter visible ports.
  - Active signal indicators (✔) show connected video feeds.

• Multi-Host Display Retention:
  - Retains displays switched to other computers as "Inactive", allowing 1-click switching back.

• Clean Startup & Reliability:
  - Starts cleanly minimized to the system tray at Windows boot without popup windows.
  - Self-contained package with zero external .NET dependencies required.
  - Improved Night Light and theme scheduling synchronization.
