Luminark is a native Windows 11 desktop application designed to unify and automate your display environment. It dynamically synchronizes Windows system and app themes with scheduled day/night times or Windows Night Light, provides direct hardware multi-monitor brightness control via DDC/CI and WMI, and offers intuitive system tray gestures for effortless control.

Key Features:

• Dynamic Theme Automation:
Automatically transitions Windows system and application themes between Light and Dark mode based on custom daytime/nighttime schedules or Windows Night Light status. Automatically adjusts daytime and nighttime brightness targets alongside theme shifts.

• Hardware Multi-Monitor Brightness Control:
Direct hardware brightness adjustment for external monitors via DDC/CI (I2C bus) and internal laptop displays via WMI. Control monitors independently or together using a synchronized Master Brightness slider.

• Monitor Video Input Source Switching:
Switch monitor inputs (DisplayPort, HDMI 1/2, USB-C) right from the quick flyout controls. Filter which ports are visible, assign custom friendly names, and see green checkmark indicators for active input signals. Retains inactive monitors switched to other devices so you can switch them back with one click.

• Taskbar Tray Scroll Wheel Control:
Hover over the Luminark tray icon and scroll your mouse wheel up or down to adjust brightness in real-time by ±5% without opening any window.

• Quick Controls Flyout:
Clean, modern Windows 11-style flyout above the system tray for instant access to brightness sliders, theme transition times, and display presets.

• Sleep & Power Management:
Prevent your PC from sleeping during long downloads or renders with configurable keep-awake timers, or use the Win+J global shortcut to lock the workstation and turn off displays while keeping the computer awake.

• Performance:
Built natively with a minimal memory footprint (~1–5 MB working set when minimized) and zero idle CPU usage.
